# Security policy

Fast Share sends images only between devices on the same local network. There is no hosted service that stores uploads.

## Report a vulnerability

Use [GitHub Security Advisories](https://github.com/alexnguyen03/fast-share/security/advisories/new) for this repository.

Please do not open a public issue for a vulnerability, and do not include real screenshots, tokens, or QR contents.

## What we care about

- A device that was never accepted pushing files onto a PC
- A reused or expired QR pairing payload
- Path or archive tricks hidden in an uploaded image
- Images leaving the local network through an unintended relay

The phone app and the PC app are both in scope.
